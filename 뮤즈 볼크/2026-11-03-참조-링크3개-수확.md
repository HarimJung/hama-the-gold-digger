## 1. 유일하게 새로 생기는 능력: Metricool MCP

지금까지 설치한 IG 스킬 13개는 전부 "내가 숫자를 붙여넣어야" 돌아간다. `/ig-audit`, `/ig-viral`, `/ig-plan`은 하마 계정 실적이 없으면 빈 껍데기다. 이 링크가 주는 건 그 구멍 하나를 메우는 경로다.

- Metricool = SNS 성과 모아 보는 서비스. 클로드에 붙이면 하마 게시물·릴스 성과 숫자를 대화로 물어볼 수 있다. 무료 플랜도 연결 가능.
- 선행 조건: Metricool 가입 + 하마 인스타 연결. 인스타는 프로페셔널(비즈니스·크리에이터) 계정이어야 한다.
- Claude Code 연결: `claude mcp add --transport http metricool https://ai.metricool.com/mcp`
  - 그 폴더에서만 보인다. 어디서나 쓰려면 `--scope user` 붙인다.
  - 그 뒤 `/mcp` → Metricool 선택 → Authenticate → 브라우저 승인.
- 앱(데스크톱·웹) 연결: 설정 → 커넥터 → 추가 → 커넥터 찾아보기 → Metricool 검색 → 연결 → Grant access.
- 안 되는 것: DM, 게시물 댓글, 광고 캠페인 관리는 Metricool MCP로 못 다룬다.
- 경고: 연결하면 클로드가 Metricool에 **예약 게시물을 만들 수 있다**(로그인한 것과 비슷한 넓은 권한). 하마 규칙(발행은 Taylor가 직접)과 부딪히는 지점. 클로드가 게시·예약을 시도하면 내용 확인하고 승인하는 단계가 필수.

예시 요청문(원문): "Metricool에서 지난 4주 내 인스타 릴스를 조회수 순으로 5개 뽑고, 저장·공유가 많은 릴스와 비교해서 공통점을 3줄로 정리해줘."

## 2. 자동 답글을 진짜로 하려면 — Meta 공식 API 조건

`/ig-reply`는 초안만 쓴다. 클로드가 직접 답글을 달게 하려면 Meta 공식 Instagram API를 붙여야 하고 조건이 이렇다.

- 인스타 프로페셔널 계정
- Meta 개발자 앱 + 댓글 권한. Instagram 로그인 방식의 `instagram_business_basic`, `instagram_business_manage_comments`. 내 계정만 쓰면 심사 없이 기본 권한. 단 앱을 "라이브"로 게시해야 댓글이 보인다.
- 그 권한으로 API를 호출하는 연동 도구가 따로 필요

누끼토끼도 이 연결은 직접 시연하지 않았다고 밝혔다. 스킬 제작자는 공식 API가 아닌 방식(브라우저 자동화 등)으로 댓글·DM을 자동으로 달면 약관 위반으로 계정이 제한될 수 있다고 안내한다. → 하마에서는 **하지 않는다**로 둔다.

## 3. 쓰기 전 경계 (하마 규칙과 그대로 일치)

- 다른 계정의 저장·도달·시청 유지율은 계정 주인만 본다. 가져올 수 없다. `/ig-viral`은 내 눈으로 보거나 붙여넣는 방식만.
- 스크래핑 같은 자동 수집 서비스 쓰지 말라고 제작자가 명시. 약관 위반 + 계정 제한.
- 댓글 단 사람의 아이디·글도 개인정보. 분석에만 쓰고 공유·재게시 금지.

## 5. clone-me — 지금 쓸 수 있는 건 뒷단 하나

11/02 결정(`브랜드-리셋/선택된-브랜드-방향.md`)은 **실제 하마 사진 + 그래픽 콜라주**다. 사람 얼굴 아바타는 필요 없다. 그래서 1~3단계(셀카 생성·목소리 클론·립싱크)는 "나중" 칸.

지금 바로 하마 릴스에 쓸 수 있는 건 4단계 마무리 레시피다. 이미 Remotion으로 MP4를 뽑고 있으니 그 뒤에 그대로 붙는다.

- 구간마다 앞 0.5초 무음 잘라내고 이어 붙이기
- 말 사이 긴 쉼 잘라내고 1.1배로 살짝 빠르게 (31초 → 24초가 됨)
- 한 줄 자막 + 화면 요소 나올 때마다 작은 클릭 소리
- 음량 -14 LUFS (처음엔 -21 LUFS로 작았다고 함)
- 클로드가 ffmpeg로 처리하고 **장면을 캡처해 직접 확인**하게 하면 실수가 줄어든다

그리고 6개 다리 사건에 직접 걸리는 한 줄이 이 글에 있다: **"기존 사진을 고치지 말고 새로 그리게 하세요. 고치기를 반복하면 얼굴이 조금씩 달라져요."** 특징(점·귀걸이·앞머리)을 프롬프트에 이름으로 박아두면 덜 바뀐다고도 적혀 있다. 하마에 옮기면 "검은 털 + 탄 포인트 + 큰 선 귀" 같은 특징을 매번 명시하고, 사지 개수를 검수 항목으로 둔다는 뜻이다.

ElevenLabs·Higgsfield 설정값은 11/02 링크 브레인 13번에 이미 있다. 그쪽이 정본.
