# 클로드 코드 자동 편집 가이드 정리 (하마용)

- 원문 링크: https://app.notion.com/p/3f9fd99f0e5f815abf07f3aedeedbb99
- 출처: 프롬왓, 2026-10-15 제작 기준, 맥에서 끝까지 실행 확인
- 한 줄 요약: 말하는 영상 하나 + 대본을 클로드 코드에 넘기면 자막, 스티커, 화면 전환까지 코드로 편집된 30초 세로 영상을 돌려받는 방식. 편집 프로그램 없이 대화만으로 숏폼 제작.

## 전제
- 30초, 세로, 한국어 기준 키트. 길이, 비율, 언어가 다르면 첫 시안이 거칠어짐.
- 첫 시안이 완성본이 아니고 2~3번 다듬는 게 정상.

## 준비물
- 클로드 유료 구독(무료 계정 불가) + 클로드 코드 설치(데스크톱 앱 Code 탭 또는 터미널 설치).
- 키트 ZIP(구글 드라이브, 로그인 불필요), 말하는 세로 영상 talk.mp4, 대본 script.txt.
- 렌더 도구(Node, 크롬, ffmpeg, Python+Pillow, 받아쓰기 도구)는 1차 요청 단계에서 클로드가 직접 설치. 권한 창이 뜨면 작업이 키트 폴더 안에 머무는 경우에만 승인.

## 흐름 0~4
- 0 준비: 클로드가 열리는 컴퓨터 만들기.
- 1 키트에 재료 넣기: 압축 푼 폴더에 talk.mp4와 script.txt를 넣어 폴더 하나로 합침. 클로드 코드를 그 폴더에서 엶.
- 2 첫 요청: 폴더 경로 + 첫 요청문을 클로드 코드 입력창에 붙여넣음. 결과는 대본에 맞춘 scene.html + 30초 시안 MP4. 클로드가 도구 설치, 프레임 추출, 받아쓰기, 스틸 확인, 렌더를 알아서 진행. 30초는 약 900프레임을 이어붙이는 방식이라 컴퓨터 성능에 따라 시간 다름. 시안은 저화질로 뽑힘.
- 3 말로 다듬기: 같은 대화에서 고칠 곳을 한 문장씩 보냄. 고친 부분만 다시 뽑아주는 부분 수정으로 지정. 만족할 때까지 반복.
- 4 마무리: 마무리 요청문 전송. 배경음은 bgm.mp3로 폴더에 미리 넣기. 결과는 고화질 MP4. 폰으로 옮겨 끝까지 보고 업로드.

## 장면 6개 (순서 고정, 안의 글자·시각만 대본에 맞게 바뀜)
- A 비교: 원본·편집본 두 창, 뒤에서 갈라지는 로고, 솟아오르는 큰 글자. 바뀌는 것: 로고 파일, 큰 글자 단어, 자막.
- B 작업 창: 클로드 코드 창에 파일이 들어가고 한 줄이 타이핑됨. 바뀌는 것: 폴더 이름, 파일 이름, 타이핑되는 한 줄.
- C 진행: 코드가 흐르고 렌더 막대가 차오름. 바뀌는 것: 라벨 문구.
- D 말로 고치기: 채팅으로 고칠 곳을 말하면 미리보기가 바뀜. 바뀌는 것: 채팅 문장 두 개, 바뀌는 색.
- E 큰 글자 판: 얼굴 옆 큰 판 두 장과 강조 판 하나. 바뀌는 것: 판 문구.
- F 댓글·DM: 댓글이 달리고 자료 페이지가 DM으로 날아감. 바뀌는 것: 댓글 단어, 페이지 제목. 유튜브판은 고정 댓글 카드.

## 클로드가 만드는 것 vs 아닌 것
- 아닌 것: 얼굴 영상과 목소리. Pollo AI(Seedance 2.5)로 뽑은 30초 한 컷과 그 목소리 그대로.
- 만드는 것: 첫 화면 나란히 보기, 단어 타이밍 자막, 스티커와 파랑 선택 박스, 초록·보라 배경 위 작업 화면, 픽셀 마스코트, 큰 글자 판, 댓글·DM 연출, 렌더 전부.
- 배경음: 따로 고른 곡을 목소리보다 작게 깔음.

## 촬영·대본 팁
- 세로 약 30초. 가로 영상은 가운데를 잘라 세로로 만들면서 손 등이 잘릴 수 있음.
- 머리 위와 가슴 아래 여백 남기기(자막·판 자리). 얼굴이 화면을 가득 채우면 글자 들어갈 자리가 없음.
- 한국어 또박또박. 받아쓰기가 한국어에 맞춰져 있어 다른 언어는 요청문에 언어 명시 필요.
- 영상에 붙은 오디오 그대로 쓰기. 다른 녹음을 더빙하면 입 모양과 자막이 어긋남.
- 대본은 말한 그대로. 문장을 다듬지 말고 순서와 띄어쓰기 유지. 견본 대본은 77단어 기준. 너무 짧거나 길면 장면이 비거나 빽빽해져 시간표를 새로 짜야 함.
- 대본이 없으면 클로드에게 받아쓰기 요청 가능. 단, 받아쓰기 오류는 직접 고쳐야 자막이 맞음.

## 시안 검수 3가지
- 자막이 말소리와 타이밍이 맞는지.
- 글자나 그래픽이 얼굴을 가리는 곳이 없는지.
- 견본 내용(클로드·어도비 얘기)이 화면 글자에 남아 있지 않은지.

## 다듬기 요령
- 한 번에 한 문장. 초 단위 또는 대사로 지목. 문제 장면 스크린샷 첨부하면 정확도 올라감.
- 부분 수정으로 지정하면 전체를 다시 렌더하지 않음.
- 한 번에 여러 요구를 몰면 화면이 복잡해짐.
- 많이 손가는 곳: 첫 시안 자막이 얼굴 가림, 다른 목소리 붙여서 립싱크 깨짐, 요구 몰아서 화면 복잡. 이 셋을 먼저 확인하면 반복 횟수가 줌.

## 마무리 규칙
- 배경음은 상업 이용 가능한 무료 음원 또는 권리 있는 곡만. 유행곡은 이 단계에서 빼고 인스타 업로드 시 앱에서 붙이기.
- 고화질 렌더는 시안보다 훨씬 오래 걸리니 모든 수정이 끝난 뒤 한 번만.

## 내 채널로 바꾸기
- 첫 장면 뒤 큰 글자(HOOK_WORD, 기본값 CLAUDE)를 영문 채널명(약 6자)으로 교체.
- 갈라지는 로고는 assets/logo.svg 교체. 권리 있는 로고·문구만 넣기.
- 타이핑 문구는 build.py의 PROMPT 교체.
- 색상은 scene.template.html 상단에서 변경(테두리·그림자 규칙은 유지).
- 마지막 장면은 프로필 링크 카드로 변경 가능. 유튜브·틱톡판은 고정 댓글 카드.
- 픽셀 마스코트 제거 가능. 픽셀 마스코트 코드는 MIT 라이선스이나 캐릭터·클로드 이름 사용 여부는 별도 확인.
- 길이 변경은 build.py의 END와 렌더 시간 옵션으로(예: 45초로 늘리고 장면 간격 재분배).
- 마음에 드는 버전은 폴더 통째로 복사해 템플릿으로. 다음 영상은 talk.mp4와 script.txt만 교체.

## 키트 파일 역할 (로고 교체 외에는 열 필요 없음)
- scene.template.html: 6장면 화면 전체. 클로드가 편집함.
- prep.py: 영상에서 프레임·오디오·단어 타이밍 추출.
- build.py: 단어 타이밍을 장면 시간표에 맞춰 scene.html 생성.
- render.mjs: scene.html을 프레임별로 캡처해 MP4 생성.
- README.md: 클로드용 지침 + 견본 대본. 견본 대본은 한 번 읽기.
- assets/: 폰트, 임시 로고, 얼굴 위치값. 로고 교체 외에는 손대지 않기.
- 얼굴 영상, 목소리, 배경음은 키트에 없음. 직접 준비.

## 못 가져온 부분 (원문 링크에서 직접 확인 필요)
- 요청문 원문(1차 요청, 다듬기 예문 4개, 마무리 요청, 키트 없는 스타일 전용 단축 요청, 다른 소재 재사용 요청 2개)은 노션 코드 블록이 로딩 상태로만 보여서 읽지 못함.
- 접힌 토글 3개(맥 수동 설치 명령, 다른 소재 요청문, 증상별 문장 모음)도 펼치지 않음.

## 하마 적용
- 얼굴 대신 하마 영상·화면 + 하마 캐릭터를 마스코트로.
- 자막, 스티커, 큰 글자 판, 댓글 달면 자료 DM으로 보내는 연출은 하마 릴스 CTA와 맞음.
- 30초 세로 포맷 그대로 사용. 첫 장면 큰 글자는 HAMA 등 영문 채널명으로 교체하는 방향.
