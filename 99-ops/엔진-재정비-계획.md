# 엔진 재정비 계획 — 손으로 한 편씩 고치지 않는다

2026-11-06 새벽 하림님: «이거 하나하나 손으로 하면 안 된다. 훅 구린 걸 다 잡아내고 훅을 엔진으로 만들어야 한다. 레퍼 모션 다양하게, 지금은 천편일률. 1→2→3→4 하나씩, 엔진부터 정하고. 레드팀 검수하고. 새 세션에서 돌릴 수 있게.»

## 하림님 기준 (11/06 새벽, 말 그대로)

1. **1초 안에 저장되고 포모 오고**, 훅으로 뭘 이야기하려는지 쉽게 설명돼서 «아 나 이거 필요해» 싶어야 한다.
2. **다양한 모션그래픽 다 쓴다** (레퍼 71가족). 천편일률 금지.
3. **쉽게 설명하지만 이해되고**, 돈 관리 → 부자 되고 싶고 가난해지기 싫은 심리를 제대로 건드린다.
4. **모든 걸 엔진으로**. 10개든 1000개든 같은 엔진이 계속 뽑는다. 한 편씩 손으로 고치지 않는다.

## 새 세션에서 돌리기 (한 세션 = 한 단계, 아래 글을 그대로 첫 메시지로)

- **1단계 (11/06 낮 완료 — 아래 «1단계 실측»)** «1단계(훅 엔진)만. 발견 1~10·16 → `hook.py felt --all` (subject·fact.felt) → `hook.py audit` → FAIL 편 `hook.py rehook --all` → `hook.py sheet` 대지 1장.»
- **2단계 (11/06 오후 완료 — 아래 «2단계 실측»)** «계획 2단계(대본 꼴). 발견 11·12·13·15·17 + kallaway 뼈대를 rail.md·hooks.json shapes/endings·director least_used 에 넣고, site.py 는 deliver/check 필드로. `director.py --stats` 분포 표. 랜덤 5편 렌더 `out/릴스/2단계-샘플/`.»
- **3단계 (11/06 밤 1라운드 돌림 — 아래 «3단계 둘째 바퀴 실측»)** «계획 3단계(효과). fx-목록 상태 열을 parts.py 실제로 갱신하고, H4 장표·D11 와이프·N2 오도미터 먼저(시험판 1편 → 내 판정), 그 다음 D14·N6·P4·N4·U13·U9·N8, T2 카라오케, TRANS 6종, 첫 장면 후보 4종. 관문: 한 편 ≥5가족, 전체 ≥25가족, 어떤 것도 50% 이하.»
- **4단계 (11/06 밤 돌림 — 아래 «11/06 밤 실측»)** «계획 4단계. `run.py rebuild --all` (폐기 2편 제외, 편마다 실패 격리, rail_prev2 보존, heard 경고) → site.py → 캐러셀 새 엔진(릴스 UI 장면 4:5 정지, 한 장 = 표 5~15항목, 검정 한 단어 금지) → 레드팀 한 번 더 → 대지 1장 + 랜덤 5편.»

**훅 공식 (정본, 11/06 하림님 «이거지» + «이걸로 해봐»)**: 한 문장 12단어 안에 세 조각 — **[이름: 이게 뭔지] + [잃은 것: 시청자 주머니 기준 차이·손해 $] + [얻는 것·욕망: 질문]**. 쉽게(6학년). 화면 세 자리: 알약 = 물건(저장하면 갖는 것) · 큰 글 = $ · 한 줄 = 문장.
- 공포: «SOXL sellers missed $71,000. Want it back?» · 비트코인: «Bitcoin sellers in 2022 missed $4,100. Scared of the next dip?»
- 복리: «Waiting 10 years cost $156,700. Still waiting?» · 세금: «Your TFSA lost $850 to US tax. Want it back?» · ETF 조합: «Hama's 2-ETF mix: $100 a month became $286,500. Want the mix?»
- 공포 seller-vs-holder 편은 하락 % 가 아니라 **판 사람이 놓친 $** (11/06 판정). 하락 % 는 둘째 장면(차트)으로.
- 심리 규칙: 훅이 «가난해지기 싫다»(손해)를 들면 lock-in 이 «부자 되고 싶다»(얻는 것)를 들고, 반대도 같다. 한 편에 둘 다 반드시.
- FAIL 은 넷뿐: 지어낸 숫자 · 매수/매도 콜 · 이름 없음 · 훅에 $ 손해/차이 없음(물건 알약 없음 포함). 나머지는 경고.

**대본 공식 (정본, 11/06 하림님 승인 «이걸로 해봐»)**: kallaway 뼈대 9칸, 모든 꼴이 이 위에 선다.
1. **Hook** 0~1초 (위 공식). 2. **Lock-in** 2~3문장: «Give me 30 seconds.» + 얻는 물건 한 줄 + 안 보면 손해가 계속된다는 한 줄. 3. **Body 1 = 차이를 눈으로**: 두 선택 나란히(판 사람 vs 든 사람, 25 vs 35) — 부품은 꼴이 정함(와이프·장표·오도미터·영수증). 4. **Rehook 1**: «근데 아무도 말 안 하는 게» / 다음 숫자 예고 / 질문. 5. **Body 2 = 왜**: 원리를 쉬운 말로, 어려운 말 하나는 같은 숨에 풀이(plain.words). 6. **Rehook 2 = 함정**: 매끄럽지 않았다 · 과거는 약속 아님 · CRA 규칙 — 믿음을 사는 장면. 7. (선택) **Body 3 = 내 숫자**: 내 행 찾는 법. 8. **Closing** 한 줄: $ 를 다시. 9. **CTA**: Comment WORD → DM 물건(= 알약과 같은 것). 끝맺음 그림은 4종 교대.
- 다양성은 감독이 least_used 로: 꼴 4 × 첫 장면 4 × 끝맺음 4 × 자막 2, 역할마다 부품 후보 ≥3, 전환 6종. 같은 조합 연속 금지.
- 관문: lock-in ≥2문장, rehook ≥2, 손해 장면 1 + 얻는 장면 1, 어려운 말은 풀이 없이 못 나감(경고), 숫자는 fact·slides·sources 밖이면 FAIL.

**캐러셀 공식 (정본, 11/06)**: 릴스를 기반으로, 릴스의 모션그래픽 UI 장면을 더 잘 보이고 더 예쁘게, 더 풍부하게 정지 카드로. 한 장 = 표 하나(5~15항목). 검정 바탕·한 단어 카드 **절대 금지** (`엔진/carousel.py` 11/06 판은 폐기 → 2026-11-07 하림님 «지울 수 있는 거 다 지워» 로 `_휴지통-2026-11-07/` 이동. 지우지 말고 쓰지 않는다).

**순서 규칙**: 단계마다 (1) 엔진 고침 (2) 47편 자동 측정 (3) 대지 한 장으로 하림님 판정 (4) 통과하면 다음 단계. 한 편씩 손 수정 없음. 단계 끝마다 이 문서의 «완료 기준» 숫자를 실측해서 적는다.

새 세션 첫 줄: 이 문서 → `99-ops/handoffs/` 최신 → 단계 번호 하나만 잡고 시작.

## 1. 훅 엔진 — 사람 손 0

  6. **Rehook 2**
  7. (선택) Body block 3 · (선택) Closing
  8. **CTA → 맞는 리드 마그넷** (우리: comment 단어 → DM → 사이트 편. 릴스가 약속한 물건과 같아야 함)

## 4. 전체 재생산 + 캐러셀 + 사이트

### ffmpeg-skill (kajisho5, 11/07 하림님 «싹 받아서 엔진에 심어») — 조사 결과
받은 곳: scratchpad `dl-ffmpeg-skill/repo` (격리, 실행은 안 함 — 외부 코드라 승인 필요). 42개 도구, 파이썬 표준 라이브러리만, 로컬 ffmpeg, 매 도구 `--json`·`--dry-run`, 기계 계약 `contract --json`, MCP 서버. 렌더러가 아니라 **손(hands)**: 자르고 재고 내보내고 검사한다. HyperFrames(우리 렌더러)를 바꾸지 않는다.

우리 파이프라인에서 비어 있는 자리 = 렌더 뒤 **납품 층**. 지금은 hyperframes render 결과를 그대로 보낸다: 라우드니스 정규화 없음, 플랫폼 스펙 검사 없음, 실제 MP4 기준 정지·검은 프레임·첫 프레임 검사 없음.

|---|---|---|
| 1 납품 검사 | `check.py OUT --platform reels --content --json` | 길이·비율·fps·코덱·−14 LUFS·TP, **frozen(정지 >3s)·black·silence·flashes·first frame flat** — 실제 파일에서. 11/06 «0초 빈 프레임» 류를 기계가 잡는다 |
