# 반복 제작 운영

## 시작 요청 예시

“$hama-content 하마 소개를 캐러셀과 30초 모션 릴스 기획으로 만들어줘.”
“$hama-content 기존 11월 3일 ETF 주제로 캐러셀과 릴스 초안 만들어줘. 보유 종목은 아직 빈칸.”
“$hama-content 이 자료를 하마 말투로 바꾸고 구조는 anatomy로 보여줘.”

공통 지시: `하마-제작실/about-me.md`와 `voice.md`를 사용한다. 외부 IG 스킬의 ~/.claude/instagram 경로 대신 이 프로젝트 자료를 사용한다. 외부 스킬의 일반적인 촬영·얼굴·판매·댓글 참여 요구는 하마 제작의 필수 조건이 아니다.

## 한 주제의 공용 입력

- id / 시리즈 / 주제 / 예정일·시간대
- 알고 나면 시청자가 이해하는 것 한 문장
- 검증된 출처 목록: URL, 확인 날짜, 근거 문장, 해당하는 숫자·주장
- Taylor가 제공한 사실과 아직 모르는 사실
- 핵심 그림: 물체·레이어·움직임·각 요소의 의미
- 장면별 글자·내레이션·시작과 끝·그림 상태
- 캐러셀 장 구성 / 릴스 타임라인 / 스토리 질문
- 주 CTA 하나 / 캡션 / 대체 텍스트
- 상태: 아이디어 → 초안 → 승인대기 → 승인됨 → 발행됨. 보류·폐기 가능.

## 제작 단계와 완료 증거

| 단계 | 입력 | 결과 | 끝났다는 증거 |
|---|---|---|---|
| 조사 | 주제·실제 기록 | 출처·빈칸 목록 | 주장마다 원문이나 제공 파일로 추적 |
| 기획 | 출처·브랜드 | 캐러셀 문구·장면 시간표 | 1편 1주제, 근거 없는 경험 없음 |
| 구조도 | 개념과 비유의 대응 | HTML/SVG | 표시값과 움직임이 같은 계산 상태 사용 |
| 캐러셀 | 장면별 정지 상태 | 1080×1350 PNG/JPG | 모든 장을 열어 한글·잘림·순서 확인 |
| 모션 | 공용 장면과 실제 음성 | 1080×1920, 30fps MP4 | 첫·중간·끝 프레임 + 전체 재생 확인 |
| 발행 준비 | 렌더·캡션 | 검수 결과·발행 묶음 | 출처·승인 상태·파일 버전 일치 |
| 학습 | 본인 인사이트 | 다음 편 변경점 하나 | 실제 수치와 측정 시점 기록 |

위 해상도는 프로젝트 제작 규격 제안이며 인스타가 요구하는 유일한 규격이라는 뜻이 아니다. UI 세이프존은 참고 가이드들의 서로 다른 값을 절대 규칙으로 섞지 않고 실제 앱 미리보기로 확인한다.

한국어 길이를 영어 WPM으로 확정하지 않는다. 오디오가 있으면 ffprobe 등으로 실제 길이를 재고 장면을 맞춘다. 무음이면 장면별 읽는 시간을 사람이 재생으로 확인한다. Whisper는 녹음·영상에서 받아쓸 때 필요하고, 이미 쓴 대본으로 제작하는 모든 작업에 필수는 아니다.

## 자동화 범위

현재 준비: 스킬·말투·기획 틀·소스. 다음 구현: 공용 콘텐츠 데이터 → 정지 이미지·MP4 내보내기 → 검수 자료 생성. 별도 연결: 예약 게시·DM·인사이트 수집.

기존 규칙대로 Taylor의 발행 승인 없이 업로드하지 않는다. 초안의 [Taylor가 채움]은 발행본에서 사라지거나, 공개하지 않는 항목으로 분리되어야 한다. 실제 제공할 자료가 없는 댓글 키워드 DM을 약속하지 않는다. 초안 승인과 인스타 발행 승인은 구분한다.

## 수정 방법

“8~12초 그림에서 라벨 두 개가 겹쳐. 이 구간만 고쳐.”처럼 장면과 문제를 지정한다. 같은 실수가 반복되면 브랜드·장면 규칙에 반영한다. 공용 데이터의 내용 수정은 두 포맷에 같이 반영하고, 포맷별 레이아웃 수정은 해당 출력에만 반영한다. 기존 볼크 원문은 새 버전 요청이 없는 한 보존한다.
