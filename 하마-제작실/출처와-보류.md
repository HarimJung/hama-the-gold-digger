# 원본 확인과 보류 목록

확인일 2026-11-02. 기존 자료의 과거 조회 기록은 이번의 새 확인과 구분한다.

## 원본을 새로 확보한 핵심 구성

- [Anatomy](https://github.com/wheresryan22/anatomy): 원본 저장소 다운로드, README·SKILL 확인. HTML/SVG 등으로 설명 그림을 만드는 스킬. 기존 요약보다 출력 경로가 다양하다. 인스타 이미지·영상은 별도 출력이 필요하다.
- [SNS 스킬](https://github.com/charlie947/social-media-skills): 17개 원본 확보, 하마에 필요한 5개 설치. LinkedIn 중심 기능과 Gemini용 프롬프트를 범용 인스타 영상 엔진으로 혼동하지 않는다.
- [Instagram agent](https://github.com/nategoldai/instagram-agent): 13개 확보·설치. 작성·분석 도구이며 계정 자동 게시 기능은 없다. 점수 도구의 한국어 한계는 스킬 지도에 재현 결과 기록.
- [Remotion 공식 스킬](https://github.com/remotion-dev/skills), [공식 안내](https://www.remotion.dev/docs/ai/skills): 자체 참조를 포함한 라우터 설치. 실제 영상 프로젝트·렌더 검증은 미완료.
- [HyperFrames](https://github.com/heygen-com/hyperframes), [공식 스킬 안내](https://github.com/heygen-com/hyperframes/blob/main/docs/guides/skills.mdx): 원본 skills·안내 확보. 대안으로 보관하고 기본 활성화하지 않음.
- [OpenDesign 공식 제작 유형 안내](https://open-design.ai/help/creation-types/): Motion design·HyperFrames 등 제작 경로 확인. 앱 설치·모델 연결·과금 확인은 하지 않음.

| Tesseract ‘영상 편집 엔진’ | 원본 도구 신원 미확인 | 동명 OCR 도구와 혼동하지 않게 의존성에서 제외 |

## 자동 게시 관련

Meta 콘텐츠 게시 공식 문서는 이번 열기에서 429/접근 실패였다. 현재 API 계정 유형·권한·토큰 조건을 확인한 것으로 쓰지 않았다. Instagram agent README의 특정 계정 연결 설명도 최신 공식 사양으로 단정하지 않는다. 추후 자동 게시 구현 시 선택한 로그인 경로의 공식 문서를 다시 확인한다. 이번 준비에는 토큰·개발자 앱·자동 게시·DM 연결이 없다.
