# 선택된 방향 — 실제 하마 사진 + 그래픽 콜라주

2026-11-02 사용자가 선택했다. 3안 중 C가 현재 기본 방향이다. 이전에 제안한 2D 캐릭터를 기본 방향으로 취급하지 않는다.

- 주인공: 이미 보유한 실제 하마 사진. 원본 얼굴·귀·몸·사지 형태를 유지한다. 사람 얼굴 촬영은 필요하지 않다.
- 그래픽: **영문 활자**(2026-11-03 확정), 밑줄, 종이, 테이프, 도형, 작은 소품. 설명 그림과 실제 사진을 역할에 따라 나눠 사용한다.
- 색: 그래픽은 골드·블랙·크림. 실제 사진의 자연색은 유지한다. 사진까지 팔레트에 맞추려고 털색·눈·옷을 재생성하지 않는다. HEX·폰트·레이아웃은 2026-11-03 승인됐다. 정본은 `엔진/template.html`.
- 캐러셀: 사진 중심 첫 장·마지막 장과 설명 그림 중심 본문을 조합할 수 있다.
- 릴스: 사진의 크롭·이동·확대와 그래픽 레이어를 연결한다. 강아지 몸이나 말하는 입을 새로 생성하는 것을 기본으로 하지 않는다.
- 아나토미: 구조 설명이 필요한 장면에 별도 그림으로 사용한다.

표지 v1은 트렌치 원본 사진을 HTML/CSS 프레임에 배치했다. 사진은 생성·누끼·리터칭·재색칠하지 않았고 프레임 안에서 크롭만 했다. 제목은 브랜딩 검토용 초안이며 31일의 특정 발행 슬롯을 대체하지 않는다. 발행 승인 없음.
