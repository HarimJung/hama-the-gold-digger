# 사용자 피드백과 현재 제작 기준

2026-11-02. 사용자가 Day1 생성 강아지의 다리가 여섯 개로 보이고 징그럽다고 평가했다. 기존 생성 캐릭터는 폐기 대상으로 기록한다. 파일은 작업 이력으로 보존하되 재사용하지 않는다.

대상: `하마-제작실/day1-studio/public/hama.png`와 이를 사용한 Day1 영상·이미지 시안. 발행 승인 없음. 브랜드 자산으로 승격하지 않는다. 새 캐릭터가 확정되기 전에는 이 프로젝트의 렌더 스크립트를 그대로 돌려 후속편을 만들지 않는다.

원인: 네 발 강아지의 몸에 물건을 드는 사람 팔을 별도 추가한 형태를 유도했고, 생성 후 사지 연결 검수를 빠뜨렸다. 렌더·디코딩·한글 검사는 캐릭터 디자인 검수를 대신하지 못한다.

현재 우선순위: 레퍼런스 수집 → 브랜드 컨셉 → 캐릭터의 형태·표정 → 피드 체계 → 짧은 동작 → 본편. 31일 주제와 하루 네 묶음 목표는 유지한다. 후속 답변에서 사용자는 실제 하마 사진 + 그래픽 콜라주를 선택했다. 최신 제작 기준은 `선택된-브랜드-방향.md`이며 생성 캐릭터 방향을 기본값으로 쓰지 않는다.
