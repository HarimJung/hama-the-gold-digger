# 하마 제작실 — 자료 진단과 운영안

기준: 2026-11-02, America/Toronto. 기존 자료는 수정하지 않고 이 폴더에 새 결과만 추가했다.

## 내가 이해한 목표

하마 더 골드 디거는 **토론토 치와와 하마가 대신 말하는 금융 여정 브랜드**다. Taylor는 얼굴을 촬영하지 않고, 소재나 실제 경험을 주면 AI가 조사·기획·대본·시각화·편집 초안을 이어서 만들기를 원한다. 캐러셀은 다시 읽고 저장하는 설명서, 모션 릴스는 움직임으로 이해시키는 짧은 영상, 아나토미는 돈과 상품의 구조를 눈에 보이게 만드는 그림 제작 도구다. AI 자체를 소개하는 계정으로 바꾸는 것이 아니다.

‘촬영 안 함’에는 두 경로가 있다. 기본은 하마 사진·캐릭터 + 도형·자막·구조도다. 원하면 나중에 본인 사진과 음성으로 만든 아바타를 별도 실험할 수 있다. 이번 발언을 얼굴 아바타 금지로 해석하지는 않았다. 지금 하마에 필요한 기본 경로에는 얼굴 복제·립싱크 서비스가 필요하지 않다.

## 지금 실제로 있는 것

- 기존 MD 21개: 브랜드, 사진 목록, 참고 링크, 제작법 요약, 31일 기획 명세.
- JPG 17개: 하마 9개·참조 8개. 목록 기준 하마 1장 중복이므로 고유 16장. 사진을 다시 요청할 필요가 없다.
- 계정: 10/31 명세에는 @hamathegolddigger 개설 완료로 기록. 10/29의 ‘미개설’보다 나중 기록을 따른다. 현재 인스타 화면과 게시 수는 이번에 확인하지 않았다.
- 기존 폴더에는 영상 엔진 코드, 완성 캐릭터 시트, 렌더된 캐러셀·MP4가 없었다. 10/31 문서는 구현 요청서이며 실행되는 엔진이 아니다.
- 로컬 Node/npm, Python 3, FFmpeg/ffprobe, Git 확인. yt-dlp는 PATH에서 찾지 못했다. Whisper, TTS 계정, 영상 렌더러 실행은 확인 전이다.

공개 원본 5개 저장소를 `sources/`에 받았다. 버전은 `외부소스-lock.json`에 커밋으로 고정했다. 스킬 설치와 프로그램 설치·렌더 성공을 구분한다.

| hama-content | 위 도구를 하마 규칙·한국어·공용 기획으로 연결 | 이 프로젝트 전용 스킬 작성 |

실제 명령과 경로는 [스킬 지도](스킬-지도.md), 당장 쓸 입력은 [운영 파일](운영.md), 첫 연습은 [시범 기획](시범-하마소개.md)을 본다.

## 추천 제작 흐름

**주제·실제 기록 → 출처 정리 → 공용 장면 기획 → 캐러셀 / 모션 릴스 / 스토리 → 검수 → Taylor 발행 승인**

같은 주제를 재사용하되, 캐러셀 장을 느리게 넘기는 것을 모션그래픽이라고 부르지 않는다. 예를 들어 ‘ETF 구조’는 캐러셀에서는 층별 설명, 릴스에서는 하마가 바구니를 열고 구성 요소가 펼쳐지는 동작으로 만든다. Anatomy 결과는 보통 HTML/SVG이므로 PNG 내보내기와 시간 기반 영상화가 별도로 필요하다. 인터랙티브 결과를 만들었다고 MP4가 생기는 것은 아니다.

기본 영상 엔진은 Remotion 하나로 제안한다. 캐릭터·글자·구조도를 장면별 컴포넌트로 재사용하는 목적에 맞는다. HyperFrames와 OpenDesign은 대안이다. 셋을 처음부터 동시에 운영할 이유는 없다. 기본 음성은 무음 자막으로도 시작할 수 있고, TTS는 필요할 때 연결한다. 음성을 넣으면 실제 오디오 길이가 장면 시간표의 기준이다.

## 먼저 할 일

1. 캐릭터 기준 사진으로 5포즈 시안을 만들고 같은 얼굴·귀·체형인지 확인한다.
2. [시범 기획](시범-하마소개.md) 하나로 캐러셀과 30초 릴스가 같은 브랜드로 나오는지 확인한다.
3. 첫 결과를 보고 색 HEX·폰트·첫 장 위치를 확정한다. 그 결과를 템플릿으로 고정한다.
4. 31일 명세의 기존 주제를 공용 데이터로 옮겨 생산한다. 하루 제작량은 실제 렌더·검수 소요를 측정한 뒤 판단한다.
5. 발행 이력과 본인 계정 인사이트를 모아 다음 주제를 조정한다.

## 아직 필요한 것

- 확정된 색 HEX·한국어 폰트·승인된 캐릭터 이미지. 실제 사진은 이미 있음.
- 한국어 목소리 선택은 옵션: 무음 / 일반 TTS / 본인 음성. 촬영은 필수 입력이 아니다.
- 여정 콘텐츠에는 Taylor의 실제 경험·숫자와 공개 범위. 빈칸을 가상의 투자 성과로 채우지 않는다.
- 실제 자동 게시를 원할 때의 계정 연결·권한·예약 발행 경로. 이번에는 연결·예약·게시하지 않았다.

## 확인 한계

일부 Notion·X·외부 가이드는 현재 도구에서 접근되지 않았다. 링크 브레인의 모든 내용을 원문 재검증한 것으로 표시하지 않는다. [출처와 보류 목록](출처와-보류.md)에 구분했다. 도구 가격·무료 크레딧·인스타 알고리즘 주장도 미검증 수치를 설정값으로 넣지 않았다.
