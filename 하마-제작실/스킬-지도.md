# 스킬 지도와 사용법

공개 원본 5개 저장소는 sources/에 있고 커밋은 외부소스-lock.json에 기록했다. 라이선스는 각 원본의 LICENSE를 확인한다. 설치는 프로젝트 안 `.agents/skills/`에만 했다. 계정 연결이나 유료 서비스 가입은 하지 않았다.

## 하마에서 쓰는 순서

| 작업 | 스킬 | 하마에서의 사용 |
|---|---|---|
| 전체 제작 연결 | hama-content | 가장 먼저 사용. 브랜드·한국어·공용 장면·검수 연결 |
| 소재 정리 | niche-research, content-matrix | 최신 출처와 이미 있는 31일 주제를 우선 활용 |
| 말투 | voice-builder | 기존 voice.md로 시작 가능. 실제 글을 받으면 나중에 정교화 |
| 첫 문장 | hook-generator, ig-reel | 사실 기반 훅 후보. 한국어 점수는 성과 지표로 쓰지 않음 |
| 캐러셀 | ig-carousel, graphic-designer | 장별 문구와 편집 가능한 HTML·이미지 제작 단계 |
| 구조 설명 | anatomy | 돈의 흐름·구성·관계가 작동하는 물체로 보이게 |
| 영상 | remotion-best-practices | 내장 create/markup/render/captions 등 참조를 필요할 때 읽기 |
| 발행 묶음 | ig-caption, ig-story, ig-repurpose | 캡션·스토리·포맷 재활용 초안 |
| 운영·검토 | ig-plan, ig-profile, ig-audit, ig-viral, ig-human | 본인 기록·인사이트가 있어야 성과 분석 가능 |
| 응대 초안 | ig-comment, ig-reply, ig-dm | 요청받은 초안에만 사용. 외부 전송 기능은 없음 |

외부 20개 + 하마 전용 1개, 진입 스킬 총 21개다. Remotion의 내부 하위 참조는 진입 스킬 개수에 중복 계산하지 않았다.

## 실행 예시

Codex의 다음 턴에서 `$hama-content 하마 소개를 캐러셀과 30초 릴스 기획으로 만들어줘`라고 요청한다. 구조도만 원하면 `$anatomy 하마의 돈 공부 작업대를 세 칸 구조로 설명해줘`라고 할 수 있다. 설치한 스킬은 다음 턴부터 사용할 수 있다. 목록이 갱신되지 않으면 같은 프로젝트에서 새 세션을 연다.

Claude Code용으로는 `.claude/skills/`에 같은 프로젝트 스킬을 가리키는 심볼릭 링크를 만들었다. `/hama-content`로 시작한다. 별도 글로벌 스킬·글로벌 말투 설정은 변경하지 않았다. 실행 인식은 새 세션에서 확인해야 한다.

IG 원본은 ~/.claude/instagram/voice.md를 읽도록 되어 있지만 하마 제작에서는 프로젝트의 하마-제작실/voice.md를 명시해서 사용한다. 원본을 다른 계정의 운영 파일로 덮어쓰지 않는다.

## 한국어 결함 재현

원본 `sources/instagram-agent/skills/ig-reel/beats.py`에 한국어 문장 두 줄을 넣어 실행했다. 실제 출력은 `0 words`, `~0.0s`였다. 정규식이 영문·숫자 중심이므로 한국어 시간을 측정하지 못한다. 스킬 묶음을 받았다고 이 검사까지 한국어에 맞는 것으로 취급하면 안 된다. 대본 길이는 실제 음성·장면 재생으로 확인한다.

## 설치와 제작의 차이

Anatomy와 Remotion 스킬은 AI가 따라 읽는 제작 지침이다. 여기 설치된 지침만으로 매일 자동 실행되거나, Remotion 런타임이 생기거나, 인스타가 연결되지는 않는다. 현재 완료는 자료·도구 준비와 기획 설계다. 완성 이미지·MP4 생성, 반복 실행 코드, 예약 게시 기능은 별도 구현 단계다.
