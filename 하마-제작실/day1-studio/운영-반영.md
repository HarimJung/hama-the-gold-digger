# 현재 운영 기준 — 채팅 원본 우선

2026-11-02 사용자 지시를 반영했다. 이 채팅에 붙여준 11/2~12/2 계획이 원본이고, 10/31 파일 §9는 같은 계획의 파일 참조다. 31일 모두 상태 아이디어, 승인 0개다. 숫자·종목·비중을 임의로 채우지 않는다.

매일 제작은 4묶음: 아침 스토리 → 점심 미니 피드 → 저녁 메인 릴스 → 밤 스토리. 따라서 원본 분량은 피드 62개, 스토리 블록 62개, 총 124블록이다. 저장 카드는 보조 산출물이며 별도 피드로 중복 계산하지 않는다. 피드만 하루 3~4개로 늘리는 변경은 이 원본에 포함되어 있지 않다.

운영은 주간 묶음 기획 → 같은 캐릭터·첫 장·색상으로 제작 → 전체 렌더 확인 → 날짜·실제 기록 입력 → 발행 승인 → 실제 성과 기록 순서다. 주간 기획은 미리 해도 가격·시장 뉴스는 발행 시점에 확인한다. 결산·실패·질문 수 같은 본인 데이터는 실제 기록이 없으면 빈칸이나 보류로 남긴다.

Day1은 실행 가능한 Remotion 프로젝트와 렌더 묶음으로 만들었다. 31일치 완성이나 무인 제작 엔진 완성을 주장하지 않는다. 앞으로 공용 장면 컴포넌트를 늘려, 날짜·시리즈·대본·실제 숫자 입력을 데이터로 분리해 반복 제작한다. Day2는 기존 계획의 SKETCH TO ETF로 이어간다.

## 재실행

이 폴더에서 `npm run dev`로 영상 편집 미리보기를 연다.
`node scripts/build-machine.mjs`는 공용 트레이 도형을 만든다.
`node scripts/render-day1.mjs`는 Day1 PNG 6장과 MP4를 다시 출력한다.
재실행 시 out/의 같은 이름은 덮어쓴다. 피드백 반영 전에는 결과를 새 버전 폴더로 보존한다.

기본 내레이션은 별도 음성 서비스 없이 무음 읽기 버전으로 만들었다. 이후 한국어 TTS를 선택하면 실제 음성 길이에 맞춰 타이밍을 다시 조정한다.
