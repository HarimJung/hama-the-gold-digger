# 하마 훅 규칙 문서

henry_upnomad STEP 03 방식. `voice.md` · `about-me.md` · 브랜딩 바이블에서 뽑았다.
**이 문서를 먼저 읽히고 그다음에 훅을 쓴다.**

- 주제: 캐나다에서 작은 돈으로 시작하는 투자 (ETF · 복리 · 절세계좌 · 크립토)
- 보는 사람: 토론토 사는 20~30대 초보. 계좌는 열었고 뭘 넣을지 모른다
- 화자: 하마 — 토론토 사는 검은 털 치와와. 1인칭. 원밀리언까지 가는 기록

---

## 1. 말투와 톤

| | |
|---|---|
| 언어 | **영어** |
| 인칭 | 하마 1인칭. `Hama` 를 3인칭으로 쓴다 — "Hama didn't sell. Hama wrote it down." |
| 문장 길이 | 짧게. 한 문장 12단어 안쪽. 긴 문장 하나에 짧은 문장 둘을 섞는다 |
| 톤 | 솔직하고 친근. 아는 척 안 함. **조롱 금지** — "모르면 바보" 결 절대 안 씀 |
| 전문 용어 | 그림으로 먼저 풀고 이름을 나중에 붙인다 |
| 축약형 | 쓴다 (`isn't` `you'll` `that's`). 안 쓰면 AI 티 검사 VOICE 점수가 떨어진다 |
| 결 | "Here's how Hama looks at it." · "No big words. Just the shape of it." |

---

## 2. 훅 쓰는 규칙 (henry 방식)

1. **정답을 말하지 않는다.** 궁금증만 남긴다. 답을 말하면 넘길 이유가 사라진다
2. **화면 글자 = 첫마디 말.** 둘이 같은 문장이다. 따로 쓰지 않는다
3. **한 줄 10단어 이하.** 화면에 띄울 글자다
4. 10개를 **서로 다른 방식**으로 쓴다 — 숫자 / 질문 / 흔한 실수 / 반전 / 내 경험 / 손해 / 이름 / 비교 / 시간 / 금지
5. 각 훅 옆에 **영상 첫마디로 말할 문장**을 한 줄씩 붙인다
6. 마지막에 10개 중 **궁금증이 제일 큰 1개**를 고르고 이유를 한 줄로

> **이전 규칙과 충돌하는 지점.** `hama-hook` 의 1초 법칙은 «손해를 숫자로 명시하라» 였다.
> 헨리 규칙은 «답을 숨겨라» 다. **헨리가 이긴다** — 답을 다 말한 훅은 점수가 높아도 안 넘긴다.
> 숫자는 넣되 **결론은 빼는 것**이 둘을 같이 지키는 길이다.

## 3. 절대 안 쓰는 표현 10개

1. `Buy this` · `사라`
2. `It will go up` · `오른다`
3. `Guaranteed` (단, `not guaranteed` 면책은 쓴다)
4. `High returns`
5. `Only buy these N`
6. 종목 이름 (SCHD·QQQ 등). 역할·성격으로 바꾼다
7. 지어낸 금액·수익률·비중
8. 은퇴 약속 · "평생 걱정 끝"
9. "영원히 들고 가라"
10. "나만 믿어" · "누구나 부자"

---

## 4. 좋은 훅 예시 3개

| 화면 글자 | 왜 좋은가 |
|---|---|
| `The tax-free account is the one that gets taxed.` | 반전. 답을 안 말한다. 9단어 |
| `Hama didn't sell. Hama wrote it down.` | 경험. 권유가 없다. 7단어 |
| `A crash makes your room bigger.` | 뒤집기. 왜인지는 안 말한다. 6단어 |

## 5. 쓰는 법 — 프롬프트 두 개 (헨리 원문 틀)

**① 주제 넣기**
```
하마 훅 규칙 문서(이 파일)를 먼저 읽어줘.
그 규칙을 꼭 지켜서 아래 주제로 캐러셀 훅 10개를 써줘.
주제: [ ]
이 편에서 알려줄 답: [ ]
```

**② 조건 이어붙이기**
```
조건
1. 정답은 말하지 말고, 끝까지 보고 싶게 궁금증만 남겨줘
2. 화면에 띄울 글자이니 한 줄 10단어 이하로 써줘
3. 10개를 서로 다른 방식으로 써줘 (숫자·질문·흔한 실수·반전·경험·손해·이름·비교·시간·금지)
4. 각 훅 옆에 첫마디로 말할 문장도 한 줄씩 붙여줘
5. 마지막에 10개 중 가장 궁금증이 큰 1개를 골라 이유를 한 줄로 알려줘
표로 정리해줘: 번호 | 화면 글자 | 첫마디 말 | 방식
```

그다음 `hookscore.py` 로 하한선(50 미만 폐기)만 확인한다. **80점을 합격증으로 쓰지 않는다** —
그 채점기는 같은 창작자의 히트/미스 판별 AUC 0.56 이라고 스스로 경고한다.
