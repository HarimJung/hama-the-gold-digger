## 682K 릴스 — 본 흐름 (화면 글자 그대로)

1. 훅: «Everyone is *editing* videos with Claude now.» 칩 «LIVE 1,284,407 editing with ✱» 숫자가 올라간다. 아바타.
2. 반전: «Give me 60 seconds and I will show…» 옆에 결제창 목업 «AI Video Editing Course · 12 modules · lifetime access · $497.00 · Pay $497 → · Setup locked». 캡션 «Stop paying…» 와 짝.
3. 01 Desktop app: «First, open the Claude desktop app» → 앱 카드 63% → OPEN → Chat · Cowork · Code → Code → 터미널 «ready · desktop app / local files: on». «not claude.ai in a browser» 취소선.
4. 02 One folder: «Then, on this computer, one folder» → AI Video Editor → Raw Footage · References · Exports 가지치기.
5. 03 Local chat: «Start a new Claude Code chat, choose Local, and select that *folder*.» → Cloud/Local 토글 → Local → `~/Desktop/AI Video Editor` ✓ → «Now, Claude can *see* and *use* your files.» → «Claude can see ✓Read ✓Write» 폴더 카드 3개.
6. 04 Five tools: «Next, Claude needs tools to actually *edit*.» → ✱ 가운데 «0/5 tools» 점선 원 → (IMG 쪽 스크린샷에서) Remotion · HyperFrames · FFmpeg · OpenAI(Whisper) · yt-dlp 가 차서 «5/5 tools».
7. 10 Claude edits: Raw Footage 폴더 → «PROMPT 03 Edit ✓Sent — Cut dead air, add captions + music, lay it out for review» → 카드 3장(Cut · Captions · Music)이 3D 로 쌓인다. «adds *captions* and lays everything out».
8. 11 Feedback: «If something feels off, just say it in *plain words*, like "make the *hook bigger*."» → THE HOOK 상자가 커진다 + 음성 파형 칩.
9. 정리: «That is the full checklist from an *empty* folder» → 레일 12칸이 위에서 아래로 체크. Start · empty folder → Desktop app → One folder → Local chat → Five tools → One prompt → Your taste → The key line → Stand out → Film & drop → Claude edits → Feedback → Finished reel.
10. 마무리 한 줄: «The tools do the cutting, but your *taste* does the rest.» → TOOLS 카드(아이콘 5) | YOUR TASTE 카드(AaAa · 색 점 5 · 곡선).
11. CTA: 파란 빛 + 아바타 + 글자 타일 E D I T O R 가 떨어진다. 댓글 키워드.

## 화면 문법 (하마로 옮길 때 기준)

- 바탕: 흰 모눈. 색은 파랑 하나 + 검정. 아바타 선화 고정, 왼쪽 레일에 단계 배지(«03 Local chat»).
- 글: 위에 한 줄씩. 핵심 단어 하나만 세리프 이탤릭 + 선택 상자. 단어가 하나씩 들어온다(«and select» → «and select that folder.»).
- 그림: 전부 UI 목업(앱 카드, 토글, 폴더, 터미널, 결제창). 사진 없음. 움직임은 글자·체크·토글·카드 쌓기뿐.
- 길이: 세 녹화 합쳐 42초 분량이고 빠진 구간이 있으니 전체는 60초 안팎 («Give me 60 seconds»).
